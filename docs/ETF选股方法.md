# ETF 多因子分析选股方法

> ⚠️ **免责声明**：本方法与配套代码为**分析框架 / 教育用途**，输出的是**客观规则信号**，
> **不构成任何投资建议或买卖推荐**。所有阈值与权重均为可调参数，请结合自身风险承受能力独立决策。
> 市场有风险，投资需谨慎。

本方法把“凭感觉选 ETF”升级为一套**系统化、可复用、可复盘**的流程，回答两个核心问题：

1. **选哪只** —— 用多因子框架对自选 ETF 打分排序；
2. **配多少** —— 在组合层面管控仓位、集中度与分散度。

---

## 一、整体流程

```
① 市场背景更新        ② 量价/估值取数        ③ 多因子打分
 (风向/政策/美股)  ──▶  (动量/估值/换手...) ──▶  (横截面排名加权)
 先验证后纳入              失败即打标记            缺失取中性+重新归一
        │                                              │
        ▼                                              ▼
④ 组合配置(核心-卫星)  ──▶  ⑤ 择时与再平衡  ──▶  ⑥ 定期复盘
 仓位/集中度/分散度          定期+阈值规则         校准权重与阈值
```

对应代码：`market_context.py`(①) → `data_provider.py`(②) → `etf_selection.py`(③④) → `config.json`(参数) → `docs/`(⑤⑥规则)。

| 跨境 | 核心/卫星 | 恒生 159920、恒生科技 513180 | 分散单一市场风险（与 A 股低相关） |

## 三、因子体系

七个因子，标准化到 0~100 后按权重加权（权重见 `config.json → weights`，和不必为 1，内部归一）。

| 因子 | 方向 | 数据来源 | 含义 |
|------|------|----------|------|
| 趋势动量 `trend_momentum` | 越高越好 | 日线 N 日收益（默认 60 日） | 顺势，强者恒强 |
| 相对强弱 `relative_strength` | 越高越好 | 该 ETF 动量 − 沪深300 动量 | 跑赢基准的超额 |
| 估值分位 `valuation` | **越低越好** | 对应指数 PE/PB 的历史分位（akshare） | 便宜买，贵卖（逆向） |
| 资金流 `fund_flow` | 越高越好 | 规模/份额变化 | 增量资金认可度 |
| 流动性 `liquidity` | **健康区间** | 换手率（落在 `turnover_good_range` 得满分） | 太低难成交、太高过热 |
| 风险 `risk` | **越低越好** | 年化波动率 | 低波动得高分（逆向） |
| 市场情绪 `market_sentiment` | 越高越好 | 验证后的新闻情绪（见第四节） | 小权重，防消息面过拟合 |

**标准化方式**：动量、相对强弱、资金流、波动率用**横截面百分位排名**（稳健于异常值）；估值分位直接用 `100 − 分位`；换手率用健康区间打分；情绪因子 `(-1~1) → (0~100)`。

**评级**：综合分 ≥`strong`(默认70)记「强」，≥`neutral`(默认45)记「中」，否则「弱」；**完整度 <30%** 时显示「数据不足」，不给过度自信的标签。

> 📌 **打分纪律**：默认联网取数后打分，**不接受手动数据进入分数**。任一因子取数失败 → 该因子标 `⚠`、取中性、并按**剩余有效因子的权重重新归一**，`完整度`字段如实反映可信度。

## 四、市场背景更新与真实性验证

每日 / 启动时更新「市场风向 / 政策变化 / 美股动向」，但**只关注与自选 ETF 相关**的信息，且**先验证后纳入**。

**采集**（`market_context.fetch_news`）：默认从白名单公开源联网抓取；**联网失败回退本地 `market_feed.json`**（本地/手动数据**仅供简报展示，不参与打分**）。

**筛选 / 过滤 / 真实性验证管线**（`validate_and_filter`，参数见 `config.json → validation`）：

1. **来源白名单**：仅采信 `news_whitelist` 中的可信域名（新华/证监会/发改委/交易所/主流财经等），其余视为低置信；
2. **时效窗口**：仅保留近 `recency_hours`（默认 48h）；
3. **去重**：标题相似度 ≥`title_dedup_similarity` 合并同一事件；
4. **多源交叉验证**：同一事件被 ≥`min_corroboration_sources`（默认 2）个**独立可信源**报道才算「**已验证**」；未达标只进简报、**不参与打分**；
5. **关键词→ETF 映射**：按 `keyword_etf_map` 把新闻映射到受影响的自选 ETF，命不中则丢弃；
6. 情绪因子只有「已验证」且置信度 ≥`sentiment_confidence_floor`（默认 0.5）才进打分。

> ⚠️ 这是**启发式可信度评估，不是事实核查**。关键词映射可能误判（如美联储“降息”被误关联到国内银行），故映射表需按需精修，且情绪因子权重刻意取小。

**手动兑备**：把当日新闻按 `market_feed.json` 的格式（`source / title / summary / url / timestamp`）录入即可；首次运行会自动生成一份示例供你替换。

## 五、组合配置原则

诊断逻辑见 `etf_selection.diagnose_portfolio`，硬约束见 `config.json → portfolio_limits`：

- **单票上限** `single_etf_max`（默认 25%）：避免单一标的主导组合；
- **单行业上限** `single_sector_max`（默认 40%）：避免板块押注；
- **总仓位区间** `position_range`（默认 50%~85%）：过高无缓冲、过低拖累收益；
- **现金缓冲** `min_cash_buffer`（默认 ≥10%）：应对回撤与再平衡弹药；
- **核心仓** 宽基占比应 ≥核心基准下限；
- **相关性分散**：A 股宽基 / 港股 / 黄金两两相关性较低，组合可显著降波动。

## 六、择时与再平衡

- **定期再平衡**：如每季度把各仓位拉回目标权重；
- **阈值再平衡**：单只偏离目标 ±5% 或触发硬约束即调整；
- **纪律**：预设止盈/止损与最大回撤容忍度，机械执行，避免情绪化；
- **市场背景**作为**情绪微调**（小权重）与风控参考，不作为唯一择时依据。

4. **扩品类**：跨「宽基/跨境/行业/商品」分散，利用低相关性降波动。

## 八、使用与调参

```bash
python data_provider.py     # 自测：量价/估值因子取数（联网）
python market_context.py    # 自测：市场背景抓取+验证+简报
python etf_selection.py     # 主程序：打分排序 + 组合诊断 + 市场简报
```

- **调参**：改 `config.json`（权重、阈值、硬约束、关键词映射、数据源白名单），**无需改代码**；
- **可选依赖**：`pip install akshare feedparser` 可提升取数完整度（估值分位、RSS 解析）；未安装会自动降级为“取数失败标记”，不影响运行。

### 联网取数失败的常见原因与排查

| 现象 | 可能原因 | 对策 |
|------|----------|------|
| 全部因子 `⚠ 待联网` | 无外网 / 需代理 | 配置 `HTTPS_PROXY`；确认能访问行情站 |
| 间歇性失败 | 数据源反爬、限频、超时 | 已内置当日缓存+超时；降低运行频率 |
| 估值分位总缺失 | 未装 akshare / 接口变动 | `pip install akshare`；或在 `config.json` 补数据源 |
| 新闻总是本地兜底 | RSS 源未配置/失效 | 在 `config.json → data_sources.news_rss` 填可用源，或手动维护 `market_feed.json` |
| 取到旧数据 | 时区/交易时段 | 注意美股盘后与 A 股盘中的更新时点 |
